Filtered launch sniper for pump.fun paper trading: it watches every fresh coin launch and buys only the ones whose first trades show strong real buy pressure (many buys, buy volume dominating sells, price already up 6–40% off launch), then exits on a hard stop, a trailing stop, and a stale rule. Fully event-driven and rewritten for speed — per batch it touches only that batch's events plus the at most 5 open positions. Small fixed size (0.20 SOL), at most 5 open positions, at most 40 buys per run.

## Run it

```sh
node main.ts
```
